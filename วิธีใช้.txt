ระบบนี้เป็นแอปหลายหน้าที่แชร์ข้อมูลกัน จึงต้องเปิดผ่าน
"เว็บเซิร์ฟเวอร์ในเครื่อง" (ดับเบิลคลิกไฟล์ html ตรงๆ จะใช้ไม่ได้)
ไฟล์ตัวช่วยข้างล่างนี้จะจัดการให้อัตโนมัติ


┌─ บน Windows  (ไม่ต้องติดตั้งอะไรเพิ่ม) ────────────────────┐
│                                                            │
│  1) แตกไฟล์ .zip ออกมาให้หมดก่อน (Extract All)             │
│  2) ดับเบิลคลิก   START-Windows.bat                         │
│  3) เบราว์เซอร์จะเปิดระบบขึ้นมาเอง                           │
│  4) ใช้งานเสร็จ ปิดหน้าต่างสีน้ำเงิน/ดำ เพื่อหยุดระบบ        │
│                                                            │
│  * ใช้ PowerShell ที่มีมากับ Windows อยู่แล้ว              │
│    ไม่ต้องติดตั้ง Python หรืออะไรเพิ่มเลย                   │
│  * ถ้า Windows เตือน "Windows protected your PC"           │
│    กด More info > Run anyway                                │
│  * ต้องมีไฟล์ server.ps1 อยู่ในโฟลเดอร์เดียวกันด้วย        │
└────────────────────────────────────────────────────────────┘

┌─ บน Mac ──────────────────────────────────────────────────┐
│                                                            │
│  1) แตกไฟล์ .zip ออกมาให้หมดก่อน                            │
│  2) ดับเบิลคลิก   START-Mac.command                         │
│     (ครั้งแรกถ้าขึ้นเตือน ให้คลิกขวา > Open > Open)         │
│  3) เบราว์เซอร์จะเปิดระบบขึ้นมาเอง                           │
│  4) ใช้งานเสร็จ ปิดหน้าต่าง Terminal เพื่อหยุดเซิร์ฟเวอร์    │
│                                                            │
│  * Mac ส่วนใหญ่มี Python อยู่แล้ว                          │
└────────────────────────────────────────────────────────────┘


┌─ วิธีสำรอง (ถ้าไฟล์ตัวช่วยไม่ทำงาน) ───────────────────────┐
│                                                            │
│  เปิด Terminal / Command Prompt                            │
│  cd เข้าไปในโฟลเดอร์นี้ แล้วพิมพ์:                          │
│                                                            │
│      python -m http.server 8765                            │
│    (Mac ใช้  python3 -m http.server 8765)                  │
│                                                            │
│  จากนั้นเปิดเบราว์เซอร์ไปที่:                                │
│      http://localhost:8765/index.html                      │
└────────────────────────────────────────────────────────────┘
